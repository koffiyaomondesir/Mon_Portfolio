Agent IA local

Un agent IA 100% local, capable d'agir, pas juste de discuter.

Conception d'un agent IA autonome tournant entièrement en local (LM Studio + Qwen3.5-4B), sans dépendance à une API cloud payante. L'agent génère du code multi-langages, crée des fichiers et dossiers réels, publie automatiquement sur GitHub avec déploiement GitHub Pages, et interagit avec des services cloud (Vercel, Supabase, Railway) via leurs API. Architecture multi-outils pensée pour tourner sur du matériel aux ressources limitées (8 Go RAM).

Vibeathon2026 — AGRILINK CI

Une marketplace agricole en économie circulaire, propulsée par l'IA.

EventGroupe En cours

Louer plutôt qu'acheter — et transformer ce qui dort chez soi en revenu.

Plateforme web de location de matériel événementiel et d'outillage, mettant en relation particuliers, loueurs professionnels et locataires en Côte d'Ivoire. Toute personne possédant du matériel sous-utilisé (marmites, brouettes, sonorisation, bâches, tentes de réception, outils...) peut le proposer à la location pour générer un revenu complémentaire. Catalogue filtrable par ville, catégorie et recherche, fiches produit détaillées (prix, localisation, propriétaire) et système de réservation en ligne. Développé en PHP natif avec base de données MySQL.
